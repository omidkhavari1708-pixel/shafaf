اگه ذخیره نشد، انگشتت رو روی عکس نگه دار و Save Image رو بزن.

توی کپ‌کات

  1. متن رو بنویس، سبک رو انتخاب کن و ذخیره در گالری رو بزن. توی آیفون از منوی اشتراک‌گذاری Save Image رو بزن؛ توی اندروید فایل میره توی Downloads.
  2. کپ‌کات: Overlay → Add overlay و عکس رو انتخاب کن.
  3. با دو انگشت اندازه و جاش رو تنظیم کن. تیتر هوک بهتره بالای سر باشه، حدود ۱۴ تا ۲۶ درصدِ بالای کادر، و حدود ۶۵٪ عرض کادر رو بگیره.
  4. طول لایه رو روی تایم‌لاین با جمله‌ات یکی کن.
  5. Animation → In → Fade in با زمان 0.3s. انیمیشن خروج نذار؛ با کات بعدی بره.
  6. فونت دیگه‌ای می‌خوای؟ توی بخش فونت + افزودن فونت خودم رو بزن و فایل فونت رو از گوشیت انتخاب کن.
  7. متن پشت سوژه: کلیپ اصلی رو Copy کن، کپی رو Overlay کن، روش Remove BG → Auto removal بزن و این لایه رو بالاتر از تیتر بذار.
