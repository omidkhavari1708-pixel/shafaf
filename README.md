# شفاف · تیترساز

تیتر شفاف و محوشونده برای ریلز بساز و یک PNG بی‌پس‌زمینه بگیر که مستقیم توی کپ‌کات موبایل به‌صورت Overlay می‌ذاری.

**باز کردن:** https://omidkhavari1708-pixel.github.io/shafaf/

## چی داره

- تیتر سه‌طبقه: کلمه‌ی کوچک بالا، کلمه‌ی اصلی، خط پایین
- چهار سبک: سفید شیشه‌ای، نیمه‌شفاف، تیره روی روشن، مشکی روی زرد
- شفافیت بالا و پایین کلمه، سایه، فاصله‌ی حروف، جای هر خط، رنگ دلخواه
- فونت فارسی نیمکت و وزیرمتن، فونت انگلیسی Inter Tight و Poppins
- **افزودن فونت خودت** (ttf، otf، woff، woff2)؛ روی همون دستگاه ذخیره میشه
- پیش‌نمایش روی پس‌زمینه‌ی اتاق، طوسی، زرد، سفید یا یک فریم از ویدیوی خودت
- خروجی معمولی یا ۲× و ذخیره‌ی مستقیم در گالری گوشی
- قابل نصب روی صفحه‌ی اصلی گوشی (Add to Home Screen)

## توی کپ‌کات

1. متن رو بنویس، سبک رو انتخاب کن و «ذخیره در گالری» رو بزن.
2. `Overlay → Add overlay` و عکس رو انتخاب کن.
3. اندازه و جاش رو با دو انگشت تنظیم کن.
4. `Animation → In → Fade in` با زمان 0.3s.

---

**Shafaf** is a mobile-first title maker for Reels. It renders a three-line title whose main word fades from opaque to translucent, then exports a transparent PNG for CapCut. Static site, no build step, no tracking: open `index.html` or serve the folder.
