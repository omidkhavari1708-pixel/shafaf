# شفاف · تیترساز

تیتر شفاف و محوشونده برای ریلز بساز و یک PNG بی‌پس‌زمینه بگیر که مستقیم توی کپ‌کات موبایل به‌صورت Overlay می‌ذاری.

**باز کردن:** https://omidkhavari1708-pixel.github.io/shafaf/

## چی داره

- با یک کلمه شروع میشه؛ هر چندتا خط خواستی اضافه کن (تا ۶)، هر خط اندازه و جای خودش رو داره
- خروجی همیشه PNG بدون پس‌زمینه‌ست؛ سبک شیشه‌ای حروفِ نیمه‌شفاف با لبه‌ی روشن داره که تصویر زیرش از لای حروف دیده میشه
- پنج سبک: شیشه‌ای، سفید محو، نیمه‌شفاف، تیره روی روشن، مشکی روی زرد
- شفافیت بالا و پایین حروف، لبه‌ی شیشه، سایه، پهنای حروف، فاصله‌ی حروف و خط‌ها، رنگ دلخواه
- فونت فارسی نیمکت و وزیرمتن، فونت انگلیسی Inter Tight و Poppins
- **افزودن فونت خودت** (ttf، otf، woff، woff2)؛ فقط توی مرورگر همون شخص ذخیره میشه و هیچ‌جا آپلود نمیشه
- پیش‌نمایش روی اتاق، شطرنجی (نشون‌دادن شفافیت)، طوسی، زرد، سفید یا یک عکس از خودت
- خروجی معمولی یا ۲× و ذخیره‌ی مستقیم در گالری گوشی
- قابل نصب روی صفحه‌ی اصلی گوشی (Add to Home Screen)

## توی کپ‌کات

1. یک کلمه بنویس، اندازه و سبک رو انتخاب کن و «ذخیره در گالری» رو بزن.
2. `Overlay → Add overlay` و عکس رو انتخاب کن.
3. اندازه و جاش رو با دو انگشت تنظیم کن.
4. `Animation → In → Fade in` با زمان 0.3s.

---

**Shafaf** is a mobile-first title maker for Reels. Start from one word, add lines with their own sizes, pick a glass or fade style, and export a transparent PNG for CapCut. User fonts stay in the visitor's own browser (IndexedDB) and are never uploaded. Static site, no build step, no tracking: open `index.html` or serve the folder.
